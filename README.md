### 📌 Featured Project

#### ⚡ [Attention Is All You Need — PyTorch & Interactive Visualizer](https://github.com/Arpitsh7/attention_is_all_you_need-implementation)
A from-scratch, research-grade implementation of the Transformer architecture (Vaswani et al., 2017), built as two connected pieces:
- **`pytorch_src/`** — modular PyTorch core: scaled dot-product & multi-head attention, sinusoidal positional encoding, position-wise feed-forward layers, Noam LR scheduler, label smoothing loss, and a full `unittest` suite (5/5 tests passing, covering shape invariants, causal masking, and gradient backprop).
- **`web_app/`** — an interactive **React + Vite** visualizer: live self-attention heatmaps, a positional-encoding waveform explorer, a clickable architecture inspector, and a step-by-step autoregressive decoding sandbox.

*This is the project I'd point to for this role — it's an actual Python backend + React frontend working together, built to explain a research paper rather than just use a library.*
